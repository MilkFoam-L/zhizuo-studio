# 阶段验证：独立任务执行与任务额度

日期：2026-09-30。基线提交 `2924761`。完整目标仍以 TASKS.md 为准，本阶段未执行生产部署。

## 已落地

- API 与独立 worker 共用 runtime/config，PostgreSQL 模式下可拆分执行；PGlite 保留单进程内嵌运行。
- 数据库事务连接由 AsyncLocalStorage 隔离，嵌套使用 savepoint；领取、续租、取消和发布使用数据库行锁及租约 token。
- 持久化提交 checkpoint。明确未提交的失效任务可重新领取；已可能提交但没有上游编号的任务进入核对，不重复 POST。
- 上传也使用持久租约、心跳和清理标记；素材引用与清理通过共享/独占锁协调。
- 任务创建与额度预占原子提交。成功确认使用、可证明未发送时释放、未知结果保留待核对；人工操作有原因与审计记录，按原上海日期窗口结算。
- 新增「用量与额度」页面和生成前的额度说明；跨日待核对列表可分页，成员只能看自己的空间。
