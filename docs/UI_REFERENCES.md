## 2. 视觉方向：安静、清晰、内容优先

保留织作的暖白与森林绿，建立稳定的三个层次：暖白页面底、白色内容表面、深绿主动作。模板预览和用户作品承担视觉丰富度。模型设置、项目列表与版本表以阅读和比较为优先。

| 参考依据 | 在织作中的具体应用 | 验收方式 |
| --- | --- | --- |
| Refero 的 Steep 文档：低彩度底色、稀少强调色、浅阴影 | 每个工作区域保持一个明确主动作；卡片用细边界，弹窗和悬浮工具使用层级阴影 | 首屏能迅速找到新建项目；选中、悬浮和禁用状态有区别 |
| Refero 的 Steep 文档：4px 间距体系、组件和页面分层 | 组件内间距使用 4/8/12/16px，内容卡片内边距 20/24px，区块间距 24/32px | 同类卡片标题、预览和动作对齐；边缘留白一致 |
| DesignMD：颜色、字体、尺寸等语义 token | 由 `shadcn-theme.css` 统一品牌色和反馈色；新样式复用已有 token | 同一角色不再出现难以区分的多个灰绿值 |
| OpenDesign：Brief → Template → Visual direction → Artifact | 新建内容首先填写商品事实，再选择模板/品牌风格，进入编辑和版本导出 | 用户不需要先理解画布节点或模型协议即可开始项目 |
| Aura 公共 CSS：语义表面变量和基础圆角 | 遵循已有 shadcn 组件接口，以主题适配品牌；沿用 Radix 的焦点与弹窗机制 | 表单、确认弹窗、标签页仍保持键盘可用 |

Steep 的 44–90px 营销标题和 80px 大区块间距主要服务展示页面。织作的项目列表、画布和表单使用下方更适合密集操作的字号与间距建议。

## 3. 建议的可执行 token

### 颜色

| 角色 | 建议值 | 使用范围 |
| --- | --- | --- |
| 页面底色 | `#f8f9f5` | 沿用现有暖白页面 |
| 内容表面 | `#ffffff` | 项目卡、表单、编辑面板 |
| 主要文字 | `#27362f` | 标题、输入内容、主要信息 |
| 次级文字 | `#627166` | 辅助说明、时间、项目元数据 |
| 主动作 | `#244d3e` / 白字 | 创建、保存、生成、导出等当前主动作 |
| 主动作 hover | `#193b2e` | 沿用现有深绿 |
| 轻强调表面 | `#eaf0e4` | 当前导航、选中模板、提示区 |
| 危险操作 | `#b3524d` / 白字 | 删除确认、明确错误反馈 |
| 结构分隔线 | `#e6e9e2` | 非交互区分隔；输入和焦点使用更明确的边界 |

依据 WCAG 相对亮度公式进行静态颜色对比计算：`#627166` 在暖白底约 **4.88:1**，在白底约 **5.16:1**；现有正文在暖白底约 **12.00:1**，主动作白字约 **9.52:1**。这些计算只证明所列纯色组合，不代表所有透明背景、disabled、图片覆盖层或浏览器状态已经通过可访问性验收。

### 字体、尺寸与密度

- 中文沿用 Noto Sans SC 和系统字体回退；标题 24–32px、分区标题 18–20px、正文和表单 14–16px、辅助元数据 12–13px。手机输入框推荐 16px。
- 中文正文行高 1.6–1.8；页面标题可用 `text-wrap: balance`。商品名称和用户输入允许换行，必要时提供完整名称查看方式。
- 数量、任务耗时和版本编号使用 `font-variant-numeric: tabular-nums`，减少刷新时宽度抖动。
- 桌面常规按钮高度 40px，手机和触控操作目标至少 44px。图标可为 16–20px，但点击区域独立于图标大小。
- 表单、按钮圆角 8–10px，卡片 12–16px；内外嵌套半径结合内边距保持协调。阴影只承担抬升层级。
- 侧栏保留约 216–224px；普通内容区最大宽度约 1280–1440px。画布使用剩余空间，窄屏通过面板切换释放编辑空间。

## 4. 当前代码对应的改进建议

以下是静态源码审阅结果，并非截图缺陷认定。实施时应由主代理结合最新代码和实际浏览器验收确认。

| Before | After | Why |
| --- | --- | --- |
| `.muted` 为 `#859086`，在暖白底约 3.14:1；部分描述为 `#9ba690`，白底约 2.55:1 | 重要辅助正文统一为 `#627166` 或等价合格组合 | 小字号元数据仍需清楚可读，浅色不能承担主要说明 |
| 窄屏断点中部分表单、按钮和说明缩至 8–11px | 正文/按钮保持 14px 左右，元数据保持至少 12px；用重排和抽屉解决空间限制 | 360–390px 屏幕无需通过缩小字体容纳桌面布局 |
| 窄屏 `.icon-button` 可降至 27×28px，部分按钮约 29–31px 高 | 触控目标至少 44px，密集桌面至少 40px；相邻点击范围不重叠 | 降低误触；通过隐藏次要工具和更多菜单控制密度 |
| 首页较大的欢迎展示位先于用户项目 | 新用户保留简洁上手指引；已有项目用户优先看到最近项目和新建入口 | 工作台首屏直接承接继续创作任务 |
| 多处硬编码灰绿颜色、字号和不同按钮高度 | 同类角色汇入现有主题与样式变量 | 降低后续增加页面时的视觉漂移 |
| hover 统一上移，可产生持续操作时的跳动感 | 常用按钮以背景、边界和轻微按压反馈为主；卡片仅在必要处变化 | 高频编辑操作反馈清晰且安静 |
| 页面使用不同浅色标签表示任务状态 | 状态同时具有文字和图标，错误带有具体恢复动作 | 用户能够区分排队、执行、失败、取消和需要核对 |

用户提供的 `make-interfaces-feel-better` 与 `emil-design-eng` 公开技能内容还支持：精准列出 transition 属性、克制高频动效、保留 reduced-motion、可打断状态过渡、对齐图标字重和完整的 hover/focus/active/loading/empty 状态。本文仅使用这些适合现有系统的设计原则，不引入额外样式框架或动画依赖。

## 5. 关键页面应用

**项目首页**：左侧稳定导航，标题和主动作同一基线；作品缩略图显示真实项目内容；元数据只保留平台、状态、更新时间。搜索与筛选放在列表上方。模板预览采用一致比例，并明确“示例模板”与真实生成内容。

**编辑工作台**：顶部显示项目名和保存状态；左侧素材/简报，中间画布，右侧仅显示当前选择的属性。生成与导出有清晰主动作，任务列表显示真实进度和错误恢复。窄屏一次打开一个侧面板，保留画布可视范围。

**模型接入**：按服务商显示连接状态和支持能力；常用字段优先，自定义协议归入高级设置。用实质性文案区分已保存、有密钥、连接验证、真实任务结果，避免单一绿色状态造成误解。

**版本对比与导出**：图片固定预览框、文案自然换行；版本名、创建时间、来源和选中状态对齐。宽屏并排，窄屏上下排列。下载格式、尺寸和选中版本数量在提交前可见。
