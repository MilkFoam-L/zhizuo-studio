# 织作工程任务与验收进度

更新：2026-10-07。目标是“面向中文电商和内容创作者的 AI 内容生产工作台，画布承接素材编排与版本管理”。首条闭环为商品事实 → 小红书图文草稿 → 可编辑海报 → 对比版本 → 导出发布素材。

本任务表保留原《AI 内容生产工作台：详细实现计划》的阶段 0–5，并纳入用户后续明确要求的多渠道与中转接口接入。原计划中“首版单一供应商”已扩展为 OpenAI 兼容、Gemini 原生和受限 JSON 异步接口；原计划的账号、对象存储、额度、公开服务验收仍然保留。

## 状态含义与当前结论

- `已完成`：已有对应产物和明确的检查证据。
- `实现待验证`：当前源码存在相关实现，仍需运行或验收证据；不等于功能已通过。
- `部分实现`：只有一部分需求存在，表格列出剩余工作。
- `未实现`：当前源码中未发现该能力。
- `后续阶段`：原计划明确延后，仍记录在完整路线中。

当前工程定位为**支持个人账号隔离、可选择本地或 S3 媒体后端，并可用 PostgreSQL 拆分 API 与多个 worker 的开发版**。本地 / 共享密码模式保留一个 `local` 空间；账号模式为每个账号建立独立个人空间，管理员可创建和停用账号。个人账号服务、HTTP 所有者隔离、S3 适配合同、数据库任务租约和每日任务额度账本已有自动化证据；真实 PostgreSQL 已验证一个 API 与多个 worker。本轮新增品牌资料库、只读分享链接和画布扩展节点（prompt / generation / annotation / group、类型化关系边、任务历史快照与备份适配），自动化已通过；浏览器交互验收仍未完成。团队成员、邀请、预签名上传、真实云端接入、实际费用结算、多 API 完整验收和公开服务验收仍未完成，不能称为完整托管 MVP 或公开 SaaS。

本表依据 README、shared 类型、API / worker / provider / media / backup、前端源码及实际执行记录更新。最新 `work/brands-shares-canvas-check.log` 证明 `npm run check` 通过：typecheck、171/171 测试、build，0 失败 / 0 跳过，覆盖品牌服务与 HTTP 隔离、分享凭证与公开白名单、画布辅助函数、任务原子生成节点、备份快照往返。此前 146/146 worker/额度门禁、`work/live-postgres-final.log` 真实 PostgreSQL 集成 1/1 和编译 worker 烟雾记录保留为历史证据。UI 静态审阅见 `UI_POLISH_REVIEW.md`。浏览器工具此前返回保存的本地访问权限拒绝；本轮将在可用的浏览器环境补真实界面验收。真实模型与 S3 服务尚未验收；真实 PostgreSQL 测试的供应商使用 fixture，没有实际收费请求。
