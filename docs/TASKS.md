# 织作工程任务与验收进度

更新：2026-09-30。目标是“面向中文电商和内容创作者的 AI 内容生产工作台，画布承接素材编排与版本管理”。首条闭环为商品事实 → 小红书图文草稿 → 可编辑海报 → 对比版本 → 导出发布素材。

本任务表保留原《AI 内容生产工作台：详细实现计划》的阶段 0–5，并纳入用户后续明确要求的多渠道与中转接口接入。原计划中“首版单一供应商”已扩展为 OpenAI 兼容、Gemini 原生和受限 JSON 异步接口；原计划的账号、对象存储、额度、公开服务验收仍然保留。

## 状态含义与当前结论

- `已完成`：已有对应产物和明确的检查证据。
- `实现待验证`：当前源码存在相关实现，仍需运行或验收证据；不等于功能已通过。
- `部分实现`：只有一部分需求存在，表格列出剩余工作。
- `未实现`：当前源码中未发现该能力。
- `后续阶段`：原计划明确延后，仍记录在完整路线中。

当前工程定位为**支持个人账号隔离、可选择本地或 S3 媒体后端的单实例开发版**。本地 / 共享密码模式保留一个 `local` 空间；账号模式为每个账号建立独立个人空间，管理员可创建和停用账号。个人账号服务、HTTP 所有者隔离和 S3 适配合同已经通过自动化检查；团队成员、邀请、预签名上传、真实云端接入、收费结算和公开服务验收仍未完成，不能称为完整托管 MVP 或公开 SaaS。

本表依据 README、shared 类型、API / worker / provider / media / backup、前端源码及实际执行记录更新。最新 `work/stage2-check.log` 证明 `npm run check` 通过：typecheck、102/102 测试、build，0 失败 / 0 跳过；阶段 2 格式检查通过。编译后的账号模式服务在独立临时数据目录通过 health、匿名请求 401 和管理员登录 200 的启动烟雾。此前 42/42、55/55 完整门禁与 50/50 恢复定向检查保留为历史记录。UI 静态审阅见 `UI_POLISH_REVIEW.md`。浏览器工具仍返回保存的本地访问权限拒绝，即使用户已多次授权，尚未取得界面实测证据；没有通过其他工具绕过拒绝。真实模型与 S3 服务尚未验收，自动化中的供应商 / S3 传输替身不代表真实服务成功。
