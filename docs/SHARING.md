# 只读分享

项目中的「只读分享」可以为 1–20 个已保存版本创建固定快照。创作者必须填写单独的公开标题、选择有效期（1–168 小时），并勾选内容确认后才能生成链接。后续编辑或新建版本不会加入已有分享；可在同一面板复制或撤销链接。

本机 `localhost` / `127.0.0.1` 地址生成的链接只能在本机打开。向其他人提供访问需要已有、可访问的私有部署地址。功能不会自动发送任何链接，也不会自动将项目发布到外部平台。

## 公开内容范围

- 文案：所选版本的标题、正文、话题标签与分页内容；不包含内部校验提醒。
- 图片：所选图片版本的 PNG 预览。
- 海报：按创建分享时的排版快照，在服务端渲染 PNG 预览。
- 不提供项目简报、原始输入快照、提示词、关联任务、服务商信息、密钥、素材名称、素材列表或原始素材直链。

版本标签、文案与海报上的文字本身属于所选内容，应由创作者在生成链接前检查。分享是持链接访问；任何收到链接的人均能在有效期内查看。撤销阻止之后的请求，无法收回收件人已保存的图片或文字。

## 凭证与失效

每个链接使用 32 字节密码学随机凭证。数据库以 SHA-256 哈希查找分享，并使用 AES-256-GCM 与分享专属 AAD 加密保管凭证，供创作者稍后再次复制。凭证位于链接的 `#/share/…` 片段，不进入网页请求路径；公开 API 通过 `X-Share-Token` 请求头接收凭证，不接受 URL 查询参数中的凭证。

公开读取与预览每次均检查有效期、撤销状态、项目归属以及当前运行模式/账号状态。不存在、凭证错误、过期、撤销、账号停用与项目不可用均返回相同的 404。反向代理日志配置应继续避免记录请求头和响应正文。服务端公开响应禁止缓存，并发送 `Referrer-Policy: no-referrer`。

创建快照和渲染预览在数据库事务中使用素材共享锁，图片与海报素材必须属于该项目。分享不会复制整份项目，也不会删除用户素材。撤销仅记录 `revokedAt`，保留创作者可见的链接记录。

## API

已登录且具有当前项目权限的请求：

- `GET /api/projects/:id/shares`：列出该项目链接。
- `POST /api/projects/:id/shares`：请求体 `{ title, versionIds, expiresHours }`。
- `POST /api/projects/:id/shares/:shareId/revoke`：撤销单个链接。

公开只读请求，均须带 `X-Share-Token`：

- `GET /api/public-shares`：读取公开标题、有效期与所选内容白名单。
- `GET /api/public-shares/versions/:id/preview`：获取已选图片/海报版本 PNG。

网页一次展示一份内容，通过上一份/下一份或选择菜单切换；仅为当前图片请求预览。切换与离开时取消请求并释放 Object URL。浏览器和服务端不将凭证存入 localStorage 或输出到控制台。

## 验证

`npx tsx --test apps/server/tests/shares.test.ts` 使用真实 PGlite、Media 素材与海报渲染，覆盖跨项目/跨空间拒绝、不可猜凭证、过期/撤销/停用/项目丢失、快照稳定、公开字段白名单、凭证加密域隔离与事务中的素材锁。HTTP 路由检查和完整构建由集成阶段执行。页面交互的真实浏览器验收仍须以本轮验证记录为准。
